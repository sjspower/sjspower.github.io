# House Social Club

## **House Social Club**

A cocktail discovery app based on the ingredients you already have.

---

## 🍸 About the App

House Social Club helps users discover cocktails using only the ingredients they already have on hand.

Key features:

- Ingredient-based cocktail search
- User-submitted recipes
- Rating system (1–5 stars and short reviews)
- Personalized recommendations based on user preferences

The goal is to make cocktail discovery simple, practical, and tailored to each user.
